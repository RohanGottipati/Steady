# Steady — Surgical Motion Trainer

Hardware-free AI surgical motion trainer that uses a laptop webcam to teach precise procedural movements through expert ghost demonstrations, real-time voice coaching, motion-level evaluation, and 3D expert-versus-user replay.

## Status

Repository bootstrap (S0) in progress. Canonical implementation reference:

- [`docs/CONTEXT.md`](docs/CONTEXT.md)

## Stack (planned)

Next.js, TypeScript, MediaPipe, React Three Fiber, Tiger Data, Backboard + Gemini, ElevenLabs.

## Getting started

1. Read `docs/IMPLEMENTATION_PLAN.md` and `docs/CONTEXT.md` before coding.
2. Work one task ID at a time from the execution plan.
3. Do not upload raw webcam frames to external services.
